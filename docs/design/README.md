# Design comparisons

`light-dark/` contains the current TVsham visual baseline at a 390 × 844
mobile viewport with the Midnight accent. It covers camera access, screen
recording, library, settings, and appearance in light and dark modes.

Open `light-dark/comparison.html` locally to browse each matched pair. The
same complete set is available as `tvsham-light-dark-screenshots.zip` for
sharing or offline review.

These are browser-rendered captures from the current app source. They are not
native-device screenshots and do not exercise camera access, secure storage,
or live recognition.
